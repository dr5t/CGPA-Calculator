# Security Policy

## Supported Versions

The following versions of AeroGrade receive active security updates and support:

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

We take the security of this project seriously. If you find any security vulnerabilities or issues, please report them directly to the developer, **Bhumika Rautela**.

To report a vulnerability:
1. Please do not open public issues.
2. Email your report to the developer or submit a detailed advisory.
3. Provide a detailed summary, steps to reproduce, and a proof of concept if available.

We will acknowledge your report within 48 hours and work with you to release a security patch in a timely manner.
